### Intellivision and Intellivoice Chips

_Intellivision CP1600_

The CP1600 is a 16-bit microprocessor created in a partnership between General Instrument and Honeywell, introduced in February 1975. It is one of the first single-chip 16-bit processors. The overall design bears a strong resemblance to the PDP-11.

* [Details](https://en.wikipedia.org/wiki/General_Instrument_CP1600)

_Intellivoice SP0250_

The SPO256 is a Speech Synthesizer chip used in many hardware Speech Synthesizers of the 8bit era. The SP0256 contains a Voice Generator, a small microprocessor, and a built-in ROM which contains 16Kbit (2Kbyte) of program code.

* [Details](https://en.wikipedia.org/wiki/General_Instrument_SP0256)
* [Phonemes](https://www.cpcwiki.eu/index.php/SP0256)
