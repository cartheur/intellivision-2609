### Specifications

# Intellivision I vs. Intellivision II Specifications

| Specification | Intellivision I / Master Component | Intellivision II |
|---|---|---|
| CPU | General Instrument CP1610, 16-bit | CP1610-compatible CPU |
| CPU clock | Approximately 894.9 kHz instruction-cycle rate | Approximately the same |
| System RAM | Approximately 1.45 KB total, including scratchpad and display memory | Approximately the same |
| Executive ROM | 4 KB of 10-bit ROM | Approximately 4.35 KB of 10-bit ROM |
| Graphics chip | General Instrument STIC | Revised STIC implementation |
| Display resolution | Approximately 159/160 × 96 pixels | Approximately 159/160 × 96 pixels |
| Colors | 16 colors | 16 colors |
| Hardware sprites | 8 | 8 |
| Sound chip | General Instrument AY-3-8914 family, 3 sound channels plus noise | AY-3-8914/AY-3-8916 family implementation |
| Cartridge connector | 44-pin edge connector | 44-pin edge connector |
| Controllers | Permanently attached to the console | Detachable controllers |
| Power supply | Internal power supply | External AC power adapter |
| Video output | RF output | RF output |
| Console case | Large wood-grain console | Smaller, lighter plastic console |
| System Changer support | Requires a hardware modification | Designed to support the System Changer |
| Executive software | Original Executive ROM | Revised Executive ROM |
| Software compatibility | Broad compatibility with original games and accessories | Some games may have timing or sound compatibility issues |
| ECS compatibility | Compatible without console modification | Compatible without console modification |

## Key Differences

- The Intellivision II is smaller and lighter.
- The Intellivision II uses detachable controllers.
- The Intellivision II uses an external power adapter.
- The Intellivision I has an internal power supply.
- The System Changer works with the Intellivision II without the original Intellivision I board modification.
- The Intellivision II uses a revised Executive ROM.
- A small number of games and accessories can behave differently on the Intellivision II because of hardware and timing changes.
- The CPU, general memory arrangement, graphics capabilities, sprite count, cartridge interface, and basic sound capabilities are broadly similar between the two systems.

## Practical Summary

The Intellivision I is generally preferred for maximum compatibility with original software and accessories. The Intellivision II is more compact and convenient because of its detachable controllers, external power supply, and native System Changer support. For practical purposes, the original Master Component is often the more broadly compatible machine with early software, while the Intellivision II is more convenient to service and use with detachable controllers and the System Changer. Neither console is universally superior: compatibility depends on the particular cartridge or accessory.
