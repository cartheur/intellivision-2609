# Intellivision ROM collection

This directory contains the 178 files extracted from the
[Intellivision ROMS archive](https://archive.org/download/Intellivision201808/ROMS.zip).

The file count is higher than the number of commercially released games because
the archive also contains prototypes, alternate versions, demonstrations, BIOS
images, homebrew software, and renamed releases.

## Original commercial library

The generally accepted original Intellivision library consists of 125
commercially released cartridges. Of these, 61 were published by Mattel
Electronics. The remaining 64 were released by INTV Corporation and third-party
publishers.

| Publisher | Released titles |
| --- | ---: |
| Mattel Electronics | 61 |
| INTV Corporation | 21 |
| Imagic | 14 |
| Coleco | 8 |
| Activision | 7 |
| Parker Brothers | 6 |
| Atarisoft | 3 |
| Dextell | 2 |
| Interphase | 2 |
| Sega | 1 |
| **Total** | **125** |

All 61 Mattel-published titles and all 125 titles in the original commercial
library are represented in this directory at the title level.

Some ROM filenames use alternate names. For example:

- `Baseball` represents *Major League Baseball*.
- `All-Star Major League Baseball` represents the game released by INTV
  Corporation as *World Championship Baseball*; the original title remains on
  its title screen.
- `World Cup Football` represents *World Cup Soccer*.

## Verification scope

This accounting compares game titles and their known aliases. It is not a
checksum audit against a modern ROM-preservation database, so it does not
certify that every file is the definitive retail dump or that prototype and
alternate-version labels are preservation-grade metadata.
