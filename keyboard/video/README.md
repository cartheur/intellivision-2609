# Keyboard Component video frames

`keyboard-component-video.mp4` is the downloaded source video.

The `frames/` directory contains one JPEG per second from `13:00` through the
end of the 16:48 video:

- `frame-0001.jpg` = 13:00
- `frame-0002.jpg` = 13:01
- `frame-0228.jpg` = approximately 16:47

`frames/contact-sheet-from-13m.jpg` is a 12-column visual index of all 228
frames. Use it to locate a subject, then open the corresponding full-size
frame for inspection.

The extracted portion includes close views of the physical Keyboard Component,
its opened chassis, keyboard, tape mechanism, internal boards, and cabling.
